# Поведение модуля при изменении period/duty при незавершённом периоде

Новые значения применяются на ближайшем rising edge clock'а:
1. Если при старом значении - `period_old` в рамках незавершённого периода произошло `n` < `period` тактов то: 
    - Незавершённый период будет продолжен и завершится, после `period` - `n` тактов
    - Если `n` < `duty`, то `pwm` = 1 следующие `duty` - `n` тактов
    - Иначе, `pwm` = 0 до конца периода
2. Если при старом значении - `period_old` в рамках незавершённого периода произошло `n` >= `period` тактов то: 
    - Незавершённый период завершается (`tick` = 1) и начинается новый длиной `period`

# Расстояние между tick

Равно `period`

# Количество высоких тактов duty

Равно `duty`
